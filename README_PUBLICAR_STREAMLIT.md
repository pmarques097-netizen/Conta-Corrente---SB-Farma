# Publicação Streamlit Cloud - V146 Estável

Configuração recomendada:

- Python: 3.11
- Main file path: app.py
- Requirements: requirements.txt

Depois de subir no GitHub, no Streamlit Cloud use:

Manage app → Settings → Reboot app

Se o app antigo estava em Python 3.14, exclua o app no Streamlit Cloud e crie novamente escolhendo Python 3.11 em Advanced settings.
